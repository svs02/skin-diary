인터랙션 명세
비교 화면 — 드래그 슬라이더
분할선(divider)과 핸들이 동일한 left: {split}% 값으로 제어됩니다.
구현: mousedown/touchstart → document에 mousemove/touchmove 등록 → left % 계산 → setState → mouseup에서 리스너 제거
범위: 5% ~ 95% (edge clamp)
초기값: 50% (중앙)
커서: cursor: ew-resize on drag area
카메라 조건 체크리스트
조건: 조명 충분, 얼굴 가이드 안에, 정면 응시 (3가지)
OK 상태: --camera-check-ok 원형 + 체크 아이콘
경고 상태: --camera-check-warn 원형 + dot
실제 구현 시 face detection API 연동 권장 (MVP는 수동 탭으로 대체 가능)
물 잔 수 입력
1~8 버튼 탭 → n <= selected 인 버튼 모두 액센트로 채워짐 (fill-up 방식)
저장: 선택한 숫자 그대로 저장. 0이면 빈 값으로 처리 (null, 0 구분 필요)
각도 전환 토스트
정면 촬영 완료 즉시 노출 → 2000ms 후 fade out (opacity 1→0, duration 300ms)
CSS: transition: opacity 300ms ease
토스트가 사라진 후에도 상단 progress dot에 완료 상태 유지
Bottom Nav 다크 모드 분리
카메라 화면(CameraGuide, CameraAngleSwitch)은 항상 다크 → NavBar에 dark=false 전달
그 외 화면은 사용자 설정 테마 따름 (data-theme="dark" 전역 토글)
UX 원칙 (구현 가이드)
01
죄책감 없는 빈 상태빈 슬롯은 점선 테두리 + 연한 배경. 빨간색·느낌표·"아직 안 했어요" 등 압박 문구 금지. 대신 "안 찍어도 괜찮아요"를 모든 선택 항목 근처에 작성.
02
한 화면 = 하나의 행동각 화면의 CTA는 1개. 보조 액션(건너뛰기, 갤러리)은 시각적으로 약하게 처리.
03
완료 상태는 조용하게완료 피드백 = 작은 초록 체크 뱃지. 애니메이션·사운드·진동 없음. 칭찬 문구("잘 했어요!") 없음.
04
스트릭은 있되 압박은 없음주간 캘린더에 기록된 날 표시. 못 한 날에 별도 강조 없음. "X일 연속" 뱃지는 긍정 강화용으로만.
05
모든 입력 항목은 선택사진 없어도 저장, 생활기록 없어도 저장. 필수 항목 0개. 저장 버튼 항상 활성.
06
반복 피로 방지매일 보는 홈 화면은 날짜만 바뀌는 구조. 새로운 요소 추가 금지. 간결함 유지.
07
에러 메시지 최소화비교 화면에서 사진 없는 날짜 선택 시 → 에러 팝업 아닌 해당 각도 비활성 + 인라인 안내. 빨간 토스트 금지.
